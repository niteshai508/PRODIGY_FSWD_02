# 👔 Employee Management System (EMS)

A full-stack web application that allows administrators to perform CRUD operations on employee records with secure authentication and role-based access control.

---

## 🚀 Features

- 🔐 Secure Login & Registration
- 👑 Role-Based Access Control (Admin/User)
- 🔑 Admin Secret Key Protection
- ➕ Add New Employee
- 📋 View All Employees
- ✏️ Edit Employee Details
- 🗑️ Delete Employee
- 🛡️ Protected Routes
- 🎨 Responsive UI with Tailwind CSS

---
